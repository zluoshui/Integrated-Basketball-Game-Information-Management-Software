# 现代界面 HTML 预览

本目录是**静态高保真预览**，用于在真实前端开发前确认信息架构与视觉方向。

## 打开方式

直接用浏览器打开：

```text
preview/modern-ui/index.html
```

Windows 也可在资源管理器中双击该文件。

## 可交互内容

- 顶栏赛事下拉：切换/创建/导入 mock
- 侧栏折叠与五模块切换（含设置）
- 队伍管理：选队 → 球员列表 → 详情/照片
- 比赛准备：独立比赛选择、名单双列
- 记分台：双侧球员卡（中文统计标签）、中央大钟、事件按钮
- 比赛日志：历史表 + 主客双列时间线；**右键日志可作废**
- 设置：球员自定义字段管理（添加/删除/排序）、导出目录
- 多个确认/编辑弹窗

## 审阅重点

1. 顶栏赛事切换是否直观
2. 队伍管理“先队后人”是否符合老师/学生习惯
3. 记分台中轴布局与中文统计标签是否清晰
4. 日志双列与右键作废是否顺手
5. 设置页字段管理是否够用
6. 蓝白/苹果风是否需要调整色值或密度

## 说明

- 数据均为假数据，不连接 SQLite
- 旧 WPF 仍用仓库根目录 `start_test_app.bat`
- 预览通过后再进入 WebView2 + API + React 真实实现
